SECTION 2 — DIGIT-LEVEL HALLUCINATION GUARD
=====================================================================

Goal: the LLM must never output a number that is not present in the
verified fact store. One hallucinated figure destroys the trust pitch.

2a. Create SEBI-main/backend/hallucination_guard.py

    class HallucinationGuard:

        def extract_numbers_from_session(self, session: dict) -> set[str]:
            """
            Walk the entire session dict recursively.
            Collect every numeric value (int, float, or numeric string).
            Normalize to strings with up to 2 decimal places.
            Also include common reformattings:
              - 18.5 → {"18.5", "18", "185", "1850000", "18,50,000"}
              - i.e. crore → lakh → unit conversions
            Return a frozenset of all allowed number strings.
            """

        def extract_numbers_from_text(self, text: str) -> list[str]:
            """
            Use regex to find all numbers in generated text.
            Pattern: r'\b\d[\d,\.]*\d\b|\b\d\b'
            Normalize each match the same way as above.
            Return list of (raw_match, normalized) tuples.
            """

        def check(self, generated_text: str, session: dict) -> GuardResult:
            """
            Returns:
              GuardResult(
                passed: bool,
                violations: list[str],   # numbers found in text but not in session
                warning_count: int,
                clean_text: str          # original text with violations marked
              )
            Each violation is marked in clean_text as:
              ⚠️[UNVERIFIED: {number}]
            """

        def assert_clean(self, generated_text: str, session: dict) -> str:
            """
            If check() finds violations, raise HallucinationDetected(violations).
            Otherwise return the original text unchanged.
            """

2b. In generator.py, after every LLM call:
    - Run HallucinationGuard().check(output, session)
    - If violations found AND generation_attempt < 3:
        - Retry the LLM call with the prompt:
          "Your previous response contained unverified numbers: {violations}.
           Rewrite using ONLY numbers from: {allowed_numbers}.
           Replace unknown numbers with [REQUIRES INPUT: description]."
        - Increment generation_attempt
    - If still failing after 3 attempts: fall back to template mode
    - Always include guard_result in the API response:
        {
          "section": "...",
          "content": "...",
          "generation_mode": "llm|template",
          "hallucination_check": {
            "passed": true/false,
            "violations_found": [],
            "retry_count": 0
          }
        }

2c. Add endpoint POST /api/validate/hallucination
    - Accepts {"section_key": "...", "content": "..."}
    - Runs HallucinationGuard().check() against current session
    - Returns the GuardResult as JSON
    - Used by the frontend to show per-section trust indicators

3a. Enhance SEBI-main/backend/consistency_checker.py

    Add class ContradictionDetector:

        def run_all_checks(self, session: dict) -> list[ContradictionFinding]:
            """
            Run every check below. Return all findings.
            Each ContradictionFinding has:
              id: str (e.g. "issue_size_mismatch")
              severity: "BLOCKER" | "MATERIAL" | "MINOR"
              title: str
              description: str
              field_a: str  (e.g. "form_data.issue_size_cr")
              value_a: Any
              field_b: str  (e.g. "bank_letter.issue_size_cr")
              value_b: Any
              difference: str  (human-readable, e.g. "₹2.5 Cr gap")
              suggested_fix: str
            """

        # Implement each check as a separate private method:

        def _check_issue_size_consistency(self, session):
            """
            Compare form_data.issue_size_cr vs bank_letter_issue_size_cr
            vs sum(objects_of_issue[].amount_cr) + gcp_amount_cr
            Flag if any two differ by more than 0.01 Cr (rounding tolerance).
            Severity: BLOCKER
            Suggested fix: "Reconcile to ₹X.XX Cr — difference is ₹Y.YY Cr"
            (compute the exact paise-level reconciling amount)
            """

        def _check_promoter_holding_consistency(self, session):
            """
            Compare form_data.promoter_holding_pct
            vs extracted_data.shareholding.promoter_holding_pct
            Flag if they differ by more than 0.1%.
            Severity: MATERIAL
            """

        def _check_gcp_cap(self, session):
            """
            Per SEBI ICDR Reg 230(2):
            GCP must be <= min(15% of issue_size, ₹10 Cr)
            Flag as BLOCKER if violated.
            Include exact cap amount in suggested_fix.
            """

        def _check_objects_arithmetic(self, session):
            """
            sum(objects_of_issue[i].amount_cr) + gcp_amount_cr
            must equal issue_size_cr (within ₹0.01 Cr tolerance).
            Flag difference as BLOCKER with exact reconciling amount.
            """

        def _check_promoter_lock_in(self, session):
            """
            Per SEBI ICDR Chapter IX:
            Promoter must hold minimum 20% post-issue, locked in for 3 years.
            Check form_data.promoter_lock_in_years >= 3
            Check post_issue_promoter_pct >= 20
            (compute post_issue_promoter_pct from existing + fresh shares)
            Flag as BLOCKER if violated.
            """

        def _check_post_issue_capital(self, session):
            """
            Per SEBI ICDR Chapter IX:
            Post-issue paid-up capital must be <= ₹25 Cr for SME IPO.
            Compute: (existing_shares_cr + fresh_issue_shares_cr) * face_value
            Flag as BLOCKER if > 25 Cr.
            """

        def _check_ebitda_track_record(self, session):
            """
            SME IPO requires operating profit (EBITDA) in at least 2 of the
            last 3 financial years.
            Check ebitda_fy24, ebitda_fy23, ebitda_fy22.
            Flag as BLOCKER if fewer than 2 are positive.
            """

        # Management Discussion, Related Party Transactions
        # For each: clause_ref must cite the actual SEBI ICDR regulation
    ]

    def compute_coverage(session: dict) -> CoverageReport:
        """
        For each requirement:
          - Check if all required_session_keys are present and non-empty
          - Weight: blocker=2.0, material=1.0, minor=0.5
        
        covered_weight = sum(weight for met requirements)
        total_weight = sum(all weights)
        score = covered_weight / total_weight * 100
        
        Returns CoverageReport:
          score: float (0-100)
          covered: int
          total: int
          by_section: dict[section_name, SectionCoverage]
          missing: list[RequirementGap]
          blocker_gaps: list[RequirementGap]  (severity=blocker only)
        
        Each RequirementGap includes:
          requirement_id, description, clause_ref, severity,
          missing_keys: list[str], suggested_action: str
        """
